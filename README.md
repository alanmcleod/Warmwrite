# WarmWrite 2.0

**A fast, distraction-free writing app designed primarily for phones.**

WarmWrite exists to make writing **easy** and **safe**.

Every feature must either:

- **Help you write**, or
- **Protect your writing.**

## Open. Write. Save.

WarmWrite uses TXT and simple RTF files so your writing is not tied to the app.

## Version 2.0

- Continue Writing home screen
- Close File
- Focus Mode
- Classic or Modern global font choice
- Quick Guide
- Settings gear and Help question mark
- Pasted text is cleaned and standardised
- Editable default Quick Symbols:
  `. , “ ” ‘ ’ ? ! — … ( ) : ; # % & £ $ €`

## Install

### iPhone / iPad
Open the live app in Safari → Share → **Add to Home Screen** → leave **Open as Web App** enabled.

### Android
Open the live app in Chrome → ⋮ → **Add to Home screen** or **Install app**.
